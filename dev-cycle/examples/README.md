# examples/

Сюда кладётся эталонная модель — одна небольшая, но настоящая, прошедшая
все шаги: из неё видно, как выглядит хороший документ каждого шага.
Навык заглядывает сюда перед первым запуском шага в новой модели.

Что положить:

- `docs/model/` одного из сервисов, уже сделанных по этому циклу, —
  целиком или срез: две-три истории со всеми шагами до задач;
- только утверждённые документы — черновик как образец учит черновикам;
- данные, которые нельзя показывать, заменить правдоподобными, сохранив
  номера и связи.

Пример должен проходить `trace.py check` без ошибок: иначе он учит
нарушениям формата.
