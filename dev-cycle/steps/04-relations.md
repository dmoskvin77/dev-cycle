# Шаг 4. Связи

Отдельный документ `relations.md`: связи между агрегатами и связи между
ролями.

- Между агрегатами: кратность и владение. Что чему принадлежит, что без
  чего не существует, что живёт самостоятельно.
- Между ролями: иерархия, включение прав, взаимное исключение.
- Каждая связь — `REL-N` с трассировкой на элементы шага 3 и на историю,
  из которой связь следует.

Связь, которую нельзя обосновать историей, — это либо забытая история,
либо ваша догадка о предметной области. Догадки помечай явно.

Останов: схема связей (mermaid) и связи без обоснования историей.

## Развилки шага

- **Владение.** Существует ли подчинённое без владельца: удаляется вместе
  с ним, остаётся само по себе или запрещает удаление.
- **Кратность.** «Один ко многим» по умолчанию — догадка. Если материал
  молчит, это вопрос.
- **Иерархия ролей.** Включает ли одна роль права другой или они
  исключают друг друга.

## Проверьте глазами

- Для каждой связи понятно, что будет при удалении владельца.
- Кратность взята из материала; догадки помечены.
- У каждой связи есть история, из которой она следует.
