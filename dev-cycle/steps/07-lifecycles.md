# Шаг 7. Жизненные циклы

Один файл на агрегат: `lifecycles/AGGR-1-<slug>.md`. Диаграмма состояний
(mermaid `stateDiagram-v2`) плюс таблица переходов.

Каждый переход `AGGR-N/TR-M`: из состояния, в состояние, по какому
событию, кто инициатор (роль), какие условия, что происходит при отказе.

Проверки, которые надо провести и показать:

- каждое состояние с шага 6 достижимо хотя бы одним переходом;
- из каждого состояния есть выход, кроме явно терминальных;
- каждый переход обоснован процессом или критерием приёмки.

Третью проверку делает `trace.py check`, он же отмечает состояния, не
упомянутые ни в одном переходе. Достижимость и выход из нетерминальных
состояний проверяешь ты, по диаграмме: скрипт не знает, какие состояния
терминальные.

Останов: результат этих трёх проверок по каждому агрегату.

## Развилки шага

- **Повторное событие.** Событие пришло второй раз: игнорировать, отказать
  или повторить действие.
- **Возврат назад.** Разрешён ли переход из позднего состояния в раннее:
  отмена оплаты, повторное открытие.
- **Таймаут.** Выводит ли время само по себе агрегат из состояния.

## Проверьте глазами

- Что будет, если событие придёт дважды или не в том состоянии?
- Из каждого нетерминального состояния есть выход, в том числе по времени.
- Терминальные состояния названы явно.
- У каждого перехода есть инициатор и поведение при отказе.
