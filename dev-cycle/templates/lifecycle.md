# Жизненный цикл AGGR-N. ⟨имя агрегата⟩

## Диаграмма

```mermaid
stateDiagram-v2
    [*] --> ⟨ST-1⟩
    ⟨ST-1⟩ --> ⟨ST-2⟩ : ⟨событие⟩
    ⟨ST-2⟩ --> [*]
```

## Переходы

| № | Из | В | Событие | Инициатор | Условия | При отказе | ← обоснование |
|---|---|---|---|---|---|---|---|
| AGGR-N/TR-1 | AGGR-N/ST-1 | AGGR-N/ST-2 | ⟨событие⟩ | ROLE-1 | ⟨условие⟩ | ⟨что происходит⟩ | PROC-1 |

## Проверки

Обоснованность переходов проверяет `trace.py check`. Эти две — по
диаграмме, скрипт не знает, какие состояния терминальные:

| Проверка | Результат |
|---|---|
| Каждое состояние достижимо | ⟨да / список недостижимых⟩ |
| Из каждого состояния есть выход (кроме терминальных) | ⟨да / список тупиков⟩ |

**Терминальные состояния:** ⟨AGGR-N/ST-M, …⟩
