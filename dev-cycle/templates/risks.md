# Реестр рисков

Сквозной документ: пополняется на любом шаге, не только на шаге 8.
Риск — то, что может обесценить работу сервиса, но не является ничьей
потребностью.

## Активные риски

### RISK-1. ⟨короткое название⟩

**Суть:** ⟨что именно может произойти и почему это плохо⟩

**← источник:** ⟨файл, реплика, собственное наблюдение⟩
**⚠ затрагивает:** USRSTR-1, PROC-2, AGGR-3
**Обработка:** критерием / решением / вне модели / принят
**Чем закрыт:** ⟨USRSTR-1/ACPT-3, NFR-2, DES-2, пункт договора, «принят, потому что …»⟩

### RISK-2. ⟨короткое название⟩

⟨…⟩

Риски без «Чем закрыт» показывает `trace.py check` на каждом останове,
пока список не опустеет. Отдельной таблицей в файле они не ведутся:
такая таблица устаревает с первой правкой.
