## 8. Верификация

Критерии приёмки и есть условия приёмки: проверяемость заложена
формулировкой. Метод верификации (test / demonstration / analysis /
inspection) задаётся по срезу — в «Как проверяется» проекта и
в `acceptance.md`; сводка по срезам — в SRS. Критерий, не вошедший ни
в один срез, идёт в «Чего в этом документе нет».
