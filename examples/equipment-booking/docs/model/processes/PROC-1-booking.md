# PROC-1. Рассмотрение заявки

**← Источники:** USRSTR-1, USRSTR-2, ROLE-1, ROLE-2, AGGR-1, REL-1, REL-2

1. Сотрудник подаёт заявку и видит её номер и статус «На рассмотрении».
2. Администратор подтверждает выбранную заявку. Если слот свободен, статус меняется на «Подтверждена».
3. Сотрудник читает статус по номеру заявки.

Попытка подтвердить заявку без роли администратора отклоняется. Если слот уже подтверждён для другой заявки, администратор видит отказ. Статусы в обоих случаях сохраняются.
