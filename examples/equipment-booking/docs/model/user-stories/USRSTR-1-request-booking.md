# USRSTR-1. Подать заявку и видеть результат

**Как** сотрудник, **я хочу** подать заявку на камеру и видеть её статус, **чтобы** знать, могу ли планировать съёмку.

**Ожидаемый результат:** сразу после отправки видна заявка на рассмотрении. После подтверждения по номеру заявки можно увидеть новый статус.

**Источник:** реплика сотрудника и согласование по Q-1 в meeting.md.

## Критерии приёмки

### USRSTR-1/ACPT-1. Подача заявки

Сразу после подачи система возвращает номер заявки и статус «На рассмотрении».

### USRSTR-1/ACPT-2. Просмотр подтверждённой заявки

После подтверждения чтение по номеру этой заявки возвращает статус «Подтверждена».
