# USRSTR-2. Подтвердить одну заявку на слот

**Как** администратор, **я хочу** самостоятельно подтверждать заявки на камеру, **чтобы** на один слот приходилась одна подтверждённая бронь.

**Ожидаемый результат:** администратор подтверждает выбранную заявку. Если слот уже подтверждён для другой заявки, система сообщает об этом.

**Источник:** реплика администратора и согласование по Q-1 в meeting.md.

## Критерии приёмки

### USRSTR-2/ACPT-1. Подтверждение администратором

Если слот свободен и администратор подтверждает заявку, она переходит в статус «Подтверждена». При попытке подтверждения сотрудником система отказывает, статус заявки остаётся прежним.

### USRSTR-2/ACPT-2. Слот уже занят

Если администратор подтверждает вторую заявку на уже занятый слот, система сообщает, что слот занят. Первая заявка остаётся подтверждённой, вторая остаётся на рассмотрении. Проверка закрывает RISK-1 в сценарии последовательных вызовов.
